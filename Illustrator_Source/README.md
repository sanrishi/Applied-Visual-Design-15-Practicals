# Illustrator Source — intentionally empty

This directory exists to hold native Adobe Illustrator `.ai` source files, but **no `.ai` files are present here.**

## Why there is no `.ai` master

Adobe Illustrator is **not installed** in this environment, so no genuine `.ai` document could be generated. Per the project's honesty policy:

- Do **not** rename an SVG or PDF to `.ai` and place it here — that is not a native Illustrator file and would misrepresent the deliverable.
- The editable source format provided instead is **SVG** (`Applied_Visual_Design_Project/SVG_Source/`). SVGs preserve live `<text>`, shapes, gradients, and clipping paths and open natively in Illustrator.
- Bundle the `Fonts/` folder when opening SVGs on another machine for exact type appearance.

## If you have Illustrator

Open any file from `SVG_Source/` in Illustrator, then `File → Save As…` and choose **Illustrator (.ai)** to create a native master. The combined master-with-15-artboards file does not exist in this environment; individual SVGs remain the editable source.

## Why there are no `.ai` files

Adobe Illustrator is **not installed** in this environment, so no genuine native Illustrator documents could be generated. Per the project's honesty policy:

- Do **not** rename an SVG or PDF to `.ai` and place it here — that is not a native Illustrator file and would misrepresent the deliverable.
- Do **not** export a PDF and rename it to `.ai`.
- Do **not** claim that `.ai` files exist when they do not.

## How to create native `.ai` files (once Illustrator is available)

1. Install Adobe Illustrator (licensed copy) on a machine where it can run.
2. Install the project fonts from `Applied_Visual_Design_Project/Fonts/` so type renders exactly.
3. Open any SVG from `SVG_Source/` in Illustrator (`File → Open`).
4. Verify text remains editable, vector objects remain editable, and no missing-font warnings appear.
5. `File → Save As…` and choose **Adobe Illustrator (.ai)** to create a genuine native `.ai` document.
6. Repeat for all 19 SVGs and place the resulting `.ai` files in this directory.

No genuine native `.ai` files can be produced in this environment because Adobe Illustrator is not installed. SVG remains the editable source format and is fully compatible with Illustrator.
